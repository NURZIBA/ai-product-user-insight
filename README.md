# AI 产品需求罗盘

> AI 智能产品用户需求与运营策划个人项目

这是一个围绕 AI 学习、办公与智能硬件场景的产品案例研究。项目从用户群体差异出发，把“识别、交互、内容生成、推荐”等技术能力翻译为具体用户任务，并设计从需求洞察到反馈迭代的运营闭环。

## 在线体验

**[点击打开在线交互演示](https://nurziba.github.io/ai-product-user-insight/)**

也可以打开 `index.html` 本地浏览。项目为纯 HTML/CSS/JavaScript，无需安装依赖。

## 项目目标

- 建立学生、职场人士、年轻消费者三类用户画像
- 从效率、易用性与场景适配角度拆解 AI 功能价值
- 形成需求—功能—指标映射，避免停留在功能罗列
- 设计拉新、激活、留存、共创四阶段运营方案
- 整理 FAQ、沟通话术与用户反馈处理机制

## 方法框架

```text
用户需求 → 产品功能 → 应用场景 → 用户反馈
   ↑                                ↓
   └──────────── 迭代学习 ──────────┘
```

项目刻意区分“研究假设”和“真实结论”。当前画像来自桌面研究与场景推演，用于展示产品分析方法；若进入真实产品决策，需要通过访谈、问卷、可用性测试和行为数据进一步验证。

## 设计亮点

- 响应式单页案例展示，支持手机与桌面浏览
- 学生 / 职场人士 / 年轻消费者画像交互切换
- 按识别 / 交互 / 生成 / 推荐筛选需求映射
- 支持系统深色模式、手动主题切换与键盘操作
- 尊重 `prefers-reduced-motion`，提供清晰焦点状态

## 后续验证

1. 每类招募 5 名目标用户进行半结构访谈。
2. 用 50+ 份问卷验证需求重要度与当前满意度。
3. 选择“会议纪要”和“学习资料总结”进行可用性测试。
4. 针对任务型内容、模板引导和反馈入口开展 A/B 测试。
